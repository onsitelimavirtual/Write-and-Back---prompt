INICIAR SEM CUSTOS DE API
1. Extraia o pacote ZIP.
2. Abra index.html num navegador atualizado; ou abra o arquivo HTML avulso.
3. Leia os documentos e registre o aceite de uso no próprio navegador.
4. Digite SUA ideia no Estúdio, confira os campos e clique em Gerar prompt profissional.
5. Confirme o nome e a versão no rodapé: Write and Back PRO 5.0.2.
6. Para começar um pedido diferente, use Limpar e digite a nova ideia.

CORREÇÕES DA VERSÃO 5.0.2
- Atualizada a identificação de versão no cabeçalho gerado, rodapé, área Sobre, exportações e documentos.
- Referência a um título de outro projeto é removida na geração, visualização e abertura de histórico.
- Dados de versões anteriores permanecem no navegador; exporte ou apague projetos antigos se preferir.
- Núcleo avançado, biblioteca, academia, QA e licenciamento preservados.
- Para publicar na web substitua o index.html anterior e faça recarregamento completo; abrir um arquivo antigo continuará mostrando a edição antiga.

IA GENERATIVA NEURAL LOCAL (OPCIONAL)
O HTML funciona com regras mesmo sem Ollama. Para usar um modelo neural gratuito,
instale voluntariamente Node.js >=20, Ollama e um modelo suportado no próprio computador.
Inicie INICIAR_LOCAL.bat (Windows compatível) ou INICIAR_LOCAL.sh (Linux/macOS),
acesse http://127.0.0.1:8787 e escolha o modelo detectado.
Não exponha a ponte local na internet. Os modelos não vêm no ZIP.

IMPORTANTE
- Não existe geração neural integrada ao HTML puro; esse modo requer instalação.
- Compatibilidade com Windows 7 e navegadores antigos não foi homologada.
- O histórico antigo não é apagado automaticamente.
- Os documentos legais são minutas sujeitas a preenchimento e revisão.
- Veja QA_RESULTADOS_5_0_2.md para resultados e limitações.
